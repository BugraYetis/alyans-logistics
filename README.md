## 📌 Proje Hakkında

1989'dan beri deniz, hava, kara ve demiryolu taşımacılığı yapan Alyans Logistics için geliştirdiğim kurumsal site. GSAP ScrollTrigger ile scroll animasyonları, savunma sanayii (NATO sertifikalı) kargo bölümü, tarihçe ve Cmd+K ile açılan site içi arama içeriyor.

|---|---|
| **Kategori** | Kurumsal Site |
| **Geliştirici** | Buğra Yetiş · MAE Reklam Ajansı |
